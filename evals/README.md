# 修订对照评测

50个自建任务：原20题覆盖改写、数字、限定语和反馈；新增30题覆盖资料证据、单位、范围、冲突、无关资料、恶意资料与显式偏好。A直接生成，B固定检查流程，C为动态工具循环。三组使用相同模型与同样授权的资料：A/B将资料放入上下文，C通过工具按需读取。分别报告上下文过大或预算不足造成的失败。

```powershell
python evals/run.py
python evals/run.py --live --limit 50 --max-calls 300
```

默认离线演示，仅验证系统与报告流程。真实评测会产生费用；全局调用上限覆盖三个策略，Agent每任务还有独立预算。报告包含逐题输出、程序检查、用量、耗时与引用。真实费用未定价时保持未知，语义成功率和人工接受率未经评分保持空值。演示调用不计入真实模型调用次数。

字符包含、长度、摘录和引用位置正确不等于结论受证据支持。应打乱并隐藏策略标签，逐题检查任务完成度、数字对应关系、证据支持程度、原意和限制条件，记录人工判定与分歧。无关资料题必须允许诚实拒答：当前严格资料模式可能停止并保留原稿，应单列为拒答，不能当作成功改写。

此公开自建集用于开发与回归，不是独立盲测基准。没有预设Agent一定更好；不能把三组不同任务子集混算为效果提升。后续增加未用于调参的留出资料，并报告重复实验的波动。
